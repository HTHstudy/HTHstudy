## Frontend Developer

“왜(WHY)?”를 기준으로 사고하며 프론트엔드 시스템을 설계합니다.

단순히 많은 프로젝트를 경험하는 것보다,  
**내가 사용하는 기술과 패턴이 어떤 문제를 해결하기 위해 등장했는지**,  
그리고 **지금 이 선택이 최선인지**를 계속 질문하는 과정을 중요하게 생각합니다.

이러한 사고 방식은  
복잡도가 커지는 프론트엔드 환경에서  
경계를 명확히 하고, 유지 가능한 구조를 만드는 데 핵심이라고 믿습니다.
