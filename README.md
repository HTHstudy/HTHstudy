## About Me

저는 단순히 기능을 구현하는 것보다,
**기술과 패턴이 어떤 문제를 해결하기 위해 등장했는지**를 이해하는 과정을 중요하게 생각합니다.

프론트엔드 개발에서 복잡도가 커질수록 중요한 것은
새로운 기술을 빠르게 도입하는 것보다,
**경계를 명확히 나누고 유지 가능한 구조를 만드는 판단력**이라고 믿습니다.

최근에는 레거시 프론트엔드 코드베이스를 개선하고,
AI Agent를 활용해 제품 개발 프로세스와 프론트엔드 개발 생산성을 높이는
**AI-Driven Product Engineering**에 관심을 두고 있습니다.
